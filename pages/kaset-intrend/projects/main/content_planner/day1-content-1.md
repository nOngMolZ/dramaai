# Day 1 - Content 1

## Content Type
Infographic / จับอาการ + แก้ปัญหา

## Title
กำจัดเพลี้ยกระโดดโดยไม่ใช้สารเคมี

## Objective
ช่วยให้คนปลูกข้าวหรือดูแลแปลงเข้าใจแนวทางลดเพลี้ยกระโดดแบบเริ่มจากการสำรวจแปลง จัดการสภาพแปลง และใช้ชีวภัณฑ์อย่างเหมาะสม ก่อนคิดถึงการใช้สารเคมี

## Key Message
เพลี้ยกระโดดลดได้ด้วยการจัดการแปลงแบบรอบด้าน: สำรวจให้ไว ไม่ปล่อยแปลงแน่น/ชื้นเกิน ลดไนโตรเจน กำจัดวัชพืช และใช้เชื้อราบิวเวอเรียเมื่อเหมาะสม

## Talking Points
- สำรวจโคนกอและใต้ใบอย่างสม่ำเสมอ
- ลดความชื้น ไม่ขังน้ำตลอดฤดูปลูก
- อย่าใส่ปุ๋ยไนโตรเจนมากเกินไป
- กำจัดวัชพืชรอบแปลง เพราะเป็นที่อาศัยของแมลง
- ใช้เชื้อราบิวเวอเรียช่วงเย็นตามคำแนะนำบนฉลาก/ผู้เชี่ยวชาญ
- หากระบาดหนัก ควรปรึกษาเจ้าหน้าที่เกษตรในพื้นที่
